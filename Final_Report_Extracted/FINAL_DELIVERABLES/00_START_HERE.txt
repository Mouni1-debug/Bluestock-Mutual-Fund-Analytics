🔥 REPORT WRITING TIPS
════════════════════════════════════════════════════════════════════════════

Using FINAL_REPORT_TEMPLATE.md:

1. EXECUTIVE SUMMARY (Top Priority)
   - Write this LAST (after you've completed everything)
   - 1 page, 5 bullet points max
   - Should tell the story: Problem → Solution → Impact
   - Key: Make it compelling for busy executives

2. TECHNICAL SECTIONS (Sections 5-9)
   - Include screenshots from your notebooks
   - Paste key charts from your analysis
   - Don't copy-paste code (just key snippets)
   - Explain WHY, not just WHAT

3. FINDINGS SECTION (Section 12)
   - Top 10 insights with evidence
   - Each insight should be 2-3 sentences
   - Include numbers from your analysis
   - End with actionable recommendation

4. RECOMMENDATIONS (Section 14)
   - Practical, implementable suggestions
   - Tie back to business impact
   - Suggest Bluestock next steps
   - Show you understand the market

5. APPENDIX (Section 16)
   - Technical details (SQL, DAX formulas)
   - Data dictionary
   - Configuration files
   - Links to code on GitHub

FORMATTING:
- Font: Arial or Segoe UI (12pt body, 24pt headings)
- Colors: Bluestock blue (#0078D4) for headings
- Spacing: 1.5 line height, justified text
- Images: 300 DPI resolution (screenshots)
- Pages: Target 15-20 pages (not 50+)
- Header/Footer: Page numbers, date, student name

DESIGN:
- Font: Segoe UI (32pt headings, 18pt body)

- Point at visuals (don't read)
- Practice beforehand

SPEAKER NOTES:
- Read presenter notes (provided in template)
- 2-3 sentences per slide
- Conversational tone
- Include statistics with context
