## How to run

```bash

# Task 3: place the 10 provided CSVs in data/raw/ (any filenames), then:

# Task 7: validate amfi_code coverage between fund_master and nav_history

```

## ⚠️ Important finding: verify the scheme code → fund name mapping

While building `live_nav_fetch.py`, scheme code **125497** was actually queried live against `https://api.mfapi.in/mf/125497`. The task brief labels this code "HDFC Top 100 Direct", but the **live API itself returned**:
```
scheme_name: "SBI SMALL CAP FUND - Direct Plan - Growth"
fund_house:  "SBI Mutual Fund"
```
This is a genuine mismatch between the task brief's labels and what the AMFI-registered API actually reports for that code — not a bug in this script. `live_nav_fetch.py` never trusts the brief's label for anything other than a comment; it always saves whatever `meta.scheme_name`/`meta.fund_house` the API returns for each code, and automatically flags the output filename with `_NAME_MISMATCH` when the two disagree (see `data/raw/nav_raw_125497_NAME_MISMATCH.csv` — this is real data actually fetched from the live API, not fabricated).

**Recommended next step:** before treating any of the 6 scheme codes as confirmed, look each one up on the [AMFI website](https://www.amfiindia.com/spages/NAVAll.txt) or run `live_nav_fetch.py` yourself and check the `api_reported_name` column against the intended fund. Full write-up in `reports/day1_data_quality_summary.md` (generated by `validate_amfi_codes.py`).

## Note on running `live_nav_fetch.py`

This scaffold's execution environment blocks outbound requests to `api.mfapi.in` (its network egress allowlist doesn't include that domain), so the script could not be run end-to-end here for all 6 schemes. It **was** verified to work correctly against the real live API for scheme 125497 via a different tool path — that reproduces exactly what `live_nav_fetch.py`'s `save_scheme_csv()` function outputs (see `data/raw/nav_raw_125497_NAME_MISMATCH.csv`). Run `python live_nav_fetch.py` from a normal machine/Colab/CI runner with unrestricted internet and it will fetch all 6 schemes' full NAV history.
